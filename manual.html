CHAPTER 01

1. 시작하기 (전체 흐름)

1.1. 프로그램 개요 및 주요 탭 안내

화면 위쪽에는 항상 고정된 세 개의 메인 탭이 있습니다. 작업 상황에 맞추어 자유롭게 이동할 수 있으며, 현재 보고 있는 탭에 밑줄이 표시됩니다.

회계 증빙 자동서식
⚙ 개인설정 🧾 문서 만들기 📋 처리 완료 목록
탭 명칭역할 및 주요 작업
⚙ 개인설정 기본 정보, 연구과제명, 예산 구분(목-세목) 등 기초 데이터를 등록합니다. (최초 1회 필수)
🧾 문서 만들기 기초자료를 입력하고 규정에 맞는 증빙 서식을 생성·검토하여 인쇄하는 상시 작업 공간입니다.
📋 처리 완료 목록 '전체서식 인쇄'를 완료한 건들이 누적 보관되며, 지출 대장을 엑셀(CSV)로 내려받습니다.

1.2. 전체 업무 진행 흐름 요약

  1. 개인설정 등록 (사전 준비): 작업 전 연구책임자 소속/성명, 과제명, 예산 목-세목을 등록합니다.
  2. 기초자료 입력: 영수증 사진 업로드, 엑셀 등록, 직접 수기 입력 중 한 방식을 택해 내용을 채웁니다.
  3. 서식 점검 및 인쇄: 예산 성격을 고르고 생성된 서식을 검토한 뒤 [전체서식 인쇄]를 실행합니다.
  4. 대장 관리: 인쇄가 완료된 건이 처리 완료 목록에 자동 기록되며 필요 시 엑셀로 백업합니다.

1.3. 화면 이동 및 입력 데이터 보존 안내

💡
화면 전환 안내 작업 도중 화면 오른쪽 위의 "⚙ 개인설정"이나 "📋 처리 완료 목록"을 열람한 뒤, 다시 "🧾 문서 만들기"를 누르면 작성 중이던 내역이 초기화되지 않고 그대로 유지됩니다.

기초자료 입력 전 본인의 정보와 과제, 예산 분류를 먼저 등록해야 합니다. 1~3번 항목을 설정하고 나면 바로 정산 작업을 시작할 수 있으며, 4~5번은 규정 확인이나 특이사항 발생 시에만 확인하시면 됩니다.

2.1. [필수] 작업 전 필수 설정 (1~3단계)필수 설정

설정 항목세부 내용 및 연동 기능

2. 연구과제 연구과제명과 SAP 과제번호 등록 (기초자료 입력 시 드롭박스 연동으로 과제번호 자동 입력)
3. 예산 구분 구분1(목) 및 구분2(세목) 목록 관리 (접이식 관리, CSV 다운로드 및 일괄 업로드 지원)

2.2. [참조] 지침 확인 및 문제 대응 설정 (4~5단계)상황별 참조

평소에는 수정할 필요가 없으며, 정산 지침이 변경되었거나 도움말 문구를 개정할 때만 펼쳐서 확인합니다.

설정 항목확인이 필요한 경우
4. 필요서류 마스터 데이터 산학협력단 회계 지침 개정으로 공통 규정·기준 안내·제출 전 확인 문구를 갱신해야 할 때 확인합니다. (이 세 문구는 화면에서 직접 수정하지 않고 '⬇ 다운로드' 후 txt 수정본을 '⬆ 업로드로 수정'하여 통째로 교체합니다. 반면 서류 목록 자체(항목명·활성 여부)는 화면에서 입력칸과 체크박스로 바로 수정합니다.)
5. 도움말 관리 화면 상단의 [❓ 도움말] 안내창에 노출되는 안내 제목과 내용을 편집하거나 새 가이드를 추가할 때 확인합니다.

2.3. 로컬 브라우저 보안 및 JSON 설정 백업·복원

⚠️
데이터 기기 내 보관 주의 등록된 설정 데이터는 정보 보안을 위해 외부 서버로 전송되지 않고 사용 중인 브라우저 내부(LocalStorage)에만 안전하게 저장됩니다. 다른 컴퓨터로 옮기거나 브라우저 캐시를 정리할 경우에 대비해 개인설정 화면 아래쪽의 [⬇ 설정 백업 다운로드]를 통해 JSON 백업 파일을 정기적으로 보관해 두세요.
CHAPTER 03

3. 기초자료 입력

개인설정이 완료된 후 영수증 정산을 시작하는 첫 화면입니다. 왼쪽 카드에서 세 가지 방식 중 하나를 선택해 데이터를 채웁니다.

3.1. 영수증 이미지 추가 (사진 자동 인식)

📎 영수증 추가 버튼을 누르거나 영수증 이미지(JPG, PNG)를 점선 박스로 끌어다 놓습니다. AI가 이미지 속 품목, 단가, 수량, 결제일자, 업체명을 자동으로 읽어 입력창에 채워 넣습니다.

3.2. 엑셀 업로드 (표준 양식 다운로드 및 일괄 등록)

버튼 옆 "⬇ 양식"으로 표준 CSV 서식을 내려받아 작성한 뒤, 📊 엑셀 업로드를 통해 다수의 품목을 한 번에 등록합니다.

3.3. 직접 입력 및 '새 작업' 데이터 초기화 주의사항

지출 내역을 직접 타이핑하거나 새 정산 건을 시작할 때 ↺ 직접 입력 / 새 작업 버튼을 누릅니다.

🛑
초기화 주의사항 이 버튼을 누르면 확인창이 나타나며, 연속 작업을 위해 보존되는 '연구과제명'을 제외한 기존 입력값(품목, 단가, 영수증 사진 등)이 완전히 초기화되므로 신중히 실행하세요.

3.4. 필수 입력 항목(지출내역) 및 품의서 목록 CSV 다운로드

  • 연구과제명 선택: 드롭박스에서 과제를 고르면 SAP 과제번호가 자동으로 채워집니다.
  • 구분1 / 구분2 선택: 예산 목과 세목을 드롭박스에서 지정합니다.
  • 지출내역 (연한 파란색 칸): 자동 입력되지 않으므로 "문구류 구매", "회의 다과비"와 같이 구체적인 지출 용도를 직접 입력해야 합니다.
  • 품의서 물품구매목록 다운로드: 품목 표 아래의 버튼을 누르면 내부 품의서 첨부용 CSV 파일을 내려받을 수 있습니다.

모든 항목을 확인했으면 왼쪽 아래의 [다음] 버튼을 눌러 체크리스트 단계로 이동합니다.

CHAPTER 04

4. 서식 체크리스트

입력된 기초자료를 바탕으로 회계 규정에 맞춘 증빙 서식들이 완성되는 화면입니다. 예산 성격에 따른 필수 서류 점검, 개별 서식 수정 및 인쇄를 진행합니다.

4.1. 예산 성격 선택 및 필수 서류 자동 분류 (110만 원 기준)

화면 왼쪽 위 드롭박스에서 '일반구매', '강사비', '업무추진비', '식사·다과비' 등을 선택하면 성격에 맞는 필수 서류 목록이 자동으로 갱신됩니다. 특히 총 구입액이 110만 원 이상일 경우 규정에 따라 '구매건 사진양식'이 자동으로 활성화됩니다.

4.2. 💡 서류 박스 클릭(미리보기) vs 네모 체크박스(업무 점검)

💡
안내 팁: 서류명 클릭 vs 체크박스의 차이
  • 서류명(박스) 클릭: 해당 서류를 누르면 가운데 화면에 실제 A4 규격 미리보기가 표시되며, 연한 파란색 칸을 직접 눌러 문구를 수정할 수 있습니다.
  • 네모 체크박스 체크: 인쇄 여부를 지정하는 것이 아니라, 담당자가 해당 서류의 출력·서명 등 최종 준비를 마쳤는지 스스로 점검하기 위한 '업무 확인용 체크리스트'입니다.

4.3. 3단 안내 탭 점검 (공통 규정 / 기준 안내 / 제출 전 확인)

화면 오른쪽 3개 탭 중 '⚠ 제출 전 확인' 탭이 기본으로 열려 있어 제출 전 필수 요건을 점검할 수 있습니다. 필요 시 '📌 공통 규정', '💡 기준 안내' 탭을 전환하며 지출 규격과 기준을 대조합니다.

📌 공통 규정 💡 기준 안내 ⚠ 제출 전 확인
  • 거래명세서: 기관명 정확성 및 인수자 성명 기재 확인
  • 물품검수조서: 거래명세서와 동일 일자, 검수자·입회자 서명 완료

4.4. 🖨 이 서식 인쇄 (개별 인쇄 시 머리글·바닥글 해제)

특정 서식 1장만 단독으로 다시 출력할 때 미리보기 화면 오른쪽 위의 [🖨 이 서식 인쇄]를 누릅니다.

⚠️
개별 서식 인쇄 시 필수 조치: "머리글 및 바닥글" 해제 개별 서식을 인쇄할 때는 브라우저 인쇄 설정창에서 "머리글 및 바닥글" 체크를 반드시 해제해야 문서 상단과 하단에 웹페이지 주소(URL)와 시스템 날짜가 인쇄되지 않습니다. (※ 개별 서식 인쇄는 단순 출력 기능이므로 '처리 완료 목록'에는 누적되지 않습니다.)

4.5. 🖨 전체서식 인쇄 (일괄 출력 및 '처리 완료 목록' 자동 누적)

해당 지출 건에 필요한 모든 서식 검토를 마쳤을 때 실행하는 최종 단계입니다. 왼쪽 서식 목록 바로 아래에 있는 진한 파란색 [🖨 전체서식 인쇄] 버튼을 누릅니다.

  1. 버튼을 누르면 체크된 모든 서식이 순서대로 연결되어 브라우저 인쇄 대화상자가 나타납니다. (전체서식 인쇄는 규격화되어 머리글·바닥글 해제 옵션을 신경 쓰지 않아도 됩니다.)
  2. 프린터 대상에서 "PDF로 저장" 또는 실물 프린터를 선택하여 출력을 완료합니다.
  3. 처리 완료 목록 자동 누적: 반드시 [🖨 전체서식 인쇄]를 실행하여 출력을 마쳐야만 해당 건이 `📋 처리 완료 목록`에 지출 내역으로 자동 등록·누적됩니다.

CHAPTER 06

6. 문제 해결 (FAQ)

6.1. 인쇄물 상·하단에 주소(URL)나 날짜가 찍힐 때

서식을 한 장씩 출력하는 개별 서식 인쇄(`이 서식 인쇄`)를 진행할 때 발생하는 현상입니다. 브라우저 인쇄 대화상자의 추가 설정에서 "머리글 및 바닥글" 체크를 해제하고 인쇄하세요. (`전체서식 인쇄` 시에는 해당하지 않습니다.)

6.2. 인쇄 후 처리 완료 목록에 내역이 나타나지 않을 때

미리보기 화면 위의 `이 서식 인쇄`(개별 인쇄)만 실행한 경우에는 대장에 기록되지 않습니다. 서식 검토를 모두 마친 후 왼쪽 서식 목록 아래의 [🖨 전체서식 인쇄]를 눌러 출력하셔야 `처리 완료 목록`에 정상적으로 누적 보관됩니다.

6.3. 다른 컴퓨터에서 작업 시 기존 데이터 복원 방법

본 웹앱은 보안을 위해 외부 서버로 데이터를 전송하지 않고 현재 PC 브라우저에만 자료를 보관합니다. 기존 PC의 "⚙ 개인설정" 화면 아래쪽에서 [⬇ 설정 백업 다운로드]로 JSON 파일을 내려받은 후, 새 PC에서 [⬆ 백업 파일 불러오기]를 실행하면 모든 설정이 즉시 복원됩니다.

6.4. '새 작업' 클릭 후 입력 내용이 지워졌을 때 대처법

해당 버튼은 다음 지출 건의 정산을 위해 입력창을 초기화하는 기능입니다. 연구과제명만 보존되고 품목 및 영수증 이미지는 완전히 삭제되므로, 작업 도중 실수로 누르지 않도록 주의하세요.

6.5. 영수증 인식이 갑자기 안 될 때

구글이 가끔 특정 인식 모델의 서비스를 종료하고 새 모델로 안내합니다. 인식이 계속 "실패"로만 뜬다면 이 문제일 수 있습니다.

  1. 이 프로그램을 만들 때 쓴 Claude 대화창에 "인식 안돼"라고 말해서 원인을 확인해달라고 요청합니다.
  2. 직접 확인하려면 GitHub 저장소의 api/recognize.js 파일에서 모델 이름이 들어간 줄을 확인합니다.
  3. 오류 메시지에 "is no longer available"(더 이상 사용할 수 없음)와 새 모델명이 안내되면, 그 이름으로 이 줄만 바꾸고 GitHub에서 "Commit changes"를 누르면 자동으로 재배포됩니다.
