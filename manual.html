📎 영수증 추가 — 사진으로 자동 인식

  1. "📎 영수증 추가"를 누르거나, 영수증 사진을 왼쪽 점선 칸에 그대로 끌어다 놓습니다(JPG, PNG 등).

  3. 다 채워지면 오른쪽 화면에서 내용이 맞는지 확인하고, 틀린 칸은 직접 고칩니다.
⚠

📊 엑셀 업로드 — 여러 건을 한 번에

  1. 버튼 옆의 "⬇ 양식"을 눌러 빈 엑셀 서식을 내려받습니다.
  2. 엑셀에 항목을 채운 뒤 저장합니다.
  3. "📊 엑셀 업로드"로 그 파일을 불러오면 오른쪽 화면이 한 번에 채워집니다.

연구과제·예산구분·필요서류처럼 자주 안 바뀌는 기초 데이터를 관리하는 화면입니다. 상단 "⚙ 개인설정" 탭에서 엽니다.

항목할 수 있는 것
1. 기본 정보연구책임자소속·성명, 담당자/연락처, 본인 이름 관리
2. 연구과제연구과제·과제번호 추가/삭제, CSV로 내려받기
3. 예산 구분구분1-구분2 목록 관리, CSV로 내려받기/올리기
4. 필요서류 마스터 데이터예산 항목별 공통 규정·기준 안내·제출 전 확인 문구, 필요서류 목록 관리
5. 도움말 관리화면 우상단 도움말 팝업에 나오는 항목 추가/수정

"4. 필요서류 마스터 데이터"의 문구 세 종류(공통 규정·기준 안내·제출 전 확인)는 화면에서 바로 고치지 않고, ⬇ 다운로드로 받은 txt 파일을 메모장이나 엑셀에서 한 줄에 한 문구씩 고친 뒤 ⬆ 업로드로 수정으로 통째로 교체하는 방식입니다.

문제 해결 / 자주 묻는 질문

인쇄물 위·아래에 날짜와 인터넷 주소가 찍혀 나와요

인쇄 대화상자에서 "머리글 및 바닥글" 체크를 해제하세요. 개별 서식 인쇄, 전체서식 인쇄 모두 마찬가지입니다.

영수증 인식이 갑자기 안 돼요

구글이 가끔 특정 인식 모델의 서비스를 종료하고 새 모델로 안내합니다. 인식이 계속 "실패"로만 뜬다면 이 문제일 수 있습니다.

  1. 이 프로그램을 만들 때 쓴 Claude 대화창에 "인식 안돼"라고 말해서 원인을 확인해달라고 요청합니다.
  2. 직접 확인하려면 GitHub 저장소의 api/recognize.js 파일에서 모델 이름이 들어간 줄을 확인합니다.
  3. 오류 메시지에 "is no longer available"(더 이상 사용할 수 없음)와 새 모델명이 안내되면, 그 이름으로 이 줄만 바꾸고 GitHub에서 "Commit changes"를 누르면 자동으로 재배포됩니다.

다른 컴퓨터에서 열었더니 설정이 하나도 없어요

개인설정·연구과제·예산구분 등은 이 브라우저에만 저장됩니다. 개인설정 맨 아래에서 받아둔 백업 파일을 새 컴퓨터의 ⬆ 백업 파일 불러오기로 올리면 그대로 복원됩니다.

"직접 입력 / 새 작업"을 눌렀더니 입력하던 내용이 사라졌어요

이 버튼은 확인 팝업까지 거쳐 데이터를 지우는 동작이라 되돌릴 수 없습니다. 연구과제명·과제번호만 남고 나머지는 모두 초기화됩니다. 평소 작업 중간중간 실수로 누르지 않도록 주의하세요.

서식 미리보기에서 고친 내용이 인쇄물에는 안 보여요

미리보기 안 파란 배경 칸을 직접 클릭해서 고친 내용은 그 서식 자체에는 반영되지만, 1단계 기초자료 화면의 원본 값과는 별도로 관리됩니다. 여러 서식에 공통으로 들어가야 하는 값이라면 1단계에서 먼저 고치는 것이 안전합니다.

더 궁금한 점이 있다면 — 이 프로그램을 만들 때 쓴 Claude 대화창에 화면을 캡처해서 물어보면 바로 확인해 드립니다.
